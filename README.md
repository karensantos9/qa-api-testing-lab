# QA API Testing Lab

Projeto de portfólio focado em testes de API.

## Objetivo

Desenvolver e demonstrar conhecimentos em testes de API,
incluindo testes funcionais, validação de contratos,
autenticação, códigos HTTP, cenários negativos e edge cases.

## Tecnologias

- Bruno
- REST API
- HTTP
- JSON
- Git
- GitHub
